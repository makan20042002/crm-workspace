# Contributing

Contributions that improve security, accessibility, Persian/English
localization, reliability or documentation are welcome.

## Before submitting a change

1. Work from the latest source release.
2. Keep hosted and offline application code identical; package-specific
   behavior belongs in configuration.
3. Do not add CDN assets, remote fonts, remote icons or mandatory external
   services.
4. Do not commit customer data, `.env`, uploads, backups, credentials or
   certificate material.
5. Run PHP syntax checks and `packaging/check-js-css-classes.ps1`.
6. Describe user-visible behavior, migration impact and testing performed.

By contributing, you agree that your contribution is licensed under
`AGPL-3.0-or-later` and that you have the right to submit it under those terms.
