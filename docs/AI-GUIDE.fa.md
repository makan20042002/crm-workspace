# راهنمای هوش مصنوعی CRM Workspace

قابل استفاده برای نسخه 10.2.0.

دستیار هوش مصنوعی اختیاری است و پس از نصب خاموش می‌ماند. تمام بخش‌های CRM بدون آن کار می‌کنند. هوش مصنوعی فقط پیش‌نویس تولید می‌کند و هیچ رکوردی را ذخیره، ارسال، حذف یا تغییر نمی‌دهد. نتیجه همیشه باید توسط یک شخص بررسی شود.

## ۱. هوش مصنوعی چه کارهایی انجام می‌دهد؟

کادر گفت‌وگوی آزاد وجود ندارد. پنج دکمه وجود دارد که هرکدام فقط یک کار مشخص انجام می‌دهند.

| دکمه | محل نمایش | کارکرد |
|---|---|---|
| خلاصه‌سازی | صفحه مشتری، فرصت و پروژه | نوشتن یک پاراگراف کوتاه از رکورد و رویدادهای اخیر |
| پیشنهاد گام بعدی | صفحه فرصت | پیشنهاد یک اقدام بعدی برای فرصت بدون فعالیت در ۷ روز گذشته |
| خواندن پیشنهاد تأمین‌کننده | صفحه استعلام | خواندن متن یا PDF و تکمیل فرم پیشنهاد تأمین‌کننده برای بررسی |
| پیش‌نویس پاسخ | پنجره ایمیل و پیامک | تبدیل دستور یک‌خطی به متن قابل ویرایش |
| ترجمه | پنجره پیام و افزودن یادداشت | ترجمه بین فارسی و انگلیسی |

دکمه‌ها با علامت ✦ مشخص می‌شوند و فقط وقتی نمایش داده می‌شوند که AI روشن و آن قابلیت فعال باشد.

## ۲. انتخاب روش اجرا

| | خاموش | مدل محلی Ollama | API ابری |
|---|---|---|---|
| هزینه | ندارد | پس از تهیه رایانه ندارد | براساس مصرف |
| نیاز به اینترنت | خیر | فقط یک‌بار برای دانلود مدل | برای هر درخواست |
| محل ارسال اطلاعات | هیچ‌جا | روی رایانه خودتان می‌ماند | به ارائه‌دهنده انتخابی ارسال می‌شود |
| کیفیت | — | وابسته به مدل و رایانه | معمولاً بهترین کیفیت |
| مناسب برای | انتخاب اولیه همه | بسته آفلاین ویندوز | بسته هاستینگ |

- **هاست اشتراکی:** امکان اجرای مدل محلی روی آن وجود ندارد؛ خاموش یا API ابری را انتخاب کنید.
- **بسته آفلاین:** مدل محلی اطلاعات را داخل دفتر نگه می‌دارد. در صورت وجود اینترنت، API ابری نیز قابل استفاده است.

## ۳. باز کردن تنظیمات هوش مصنوعی

1. با حساب مدیر وارد شوید.
2. صفحه **تنظیمات** را باز کنید.
3. بالای صفحه روی **✦ تنظیمات هوش مصنوعی** بزنید.

در installer نیز بخش AI وجود دارد، اما می‌توانید آن را خاموش بگذارید و بعداً تنظیم کنید.

## ۴. راه‌اندازی مدل محلی

### با نصب‌کننده آفلاین ویندوز

هنگام نصب، گزینه اختیاری AI و اندازه مدل را انتخاب کنید. نصب‌کننده Ollama و مدل را دانلود می‌کند؛ هیچ مدلی داخل فایل نصب قرار ندارد و این مرحله یک‌بار به اینترنت نیاز دارد.

| اندازه | مدل پیشنهادی |
|---|---|
| کوچک | `qwen2.5:3b` |
| متوسط | `qwen2.5:7b` |
| بزرگ | `qwen2.5:14b` |

اندازه را براساس حافظه رایانه انتخاب کنید. مدل بزرگ‌تر معمولاً بهتر می‌نویسد، اما کندتر پاسخ می‌دهد.

### نصب دستی

1. Ollama را از ollama.com نصب کنید.
2. یک مدل را در ترمینال دانلود کنید؛ برای نمونه:

```
ollama pull qwen2.5:3b
```

3. Ollama را در حال اجرا نگه دارید.

### سپس در تنظیمات AI

1. ارائه‌دهنده را روی **مدل محلی (Ollama)** بگذارید.
2. آدرس پایه را `http://127.0.0.1:11434/v1` نگه دارید.
3. **ذخیره** را بزنید.
4. **یافتن مدل‌ها** را بزنید و یک مدل انتخاب کنید.
5. مهلت پاسخ را روی ۱۲۰ ثانیه نگه دارید؛ برای رایانه کند می‌توانید آن را بیشتر کنید.
6. ذخیره کنید و سپس **آزمایش اتصال** را بزنید.

قبل از یافتن مدل‌ها یا آزمایش اتصال، تنظیمات را ذخیره کنید؛ این دو دکمه از تنظیمات ذخیره‌شده استفاده می‌کنند.

## ۵. راه‌اندازی API ابری

API ابری خدمتی پولی و جدا از اشتراک‌های چت است.

1. نزد یک ارائه‌دهنده سازگار، حساب API و روش پرداخت بسازید.
2. کلید API بسازید و مانند رمز عبور از آن محافظت کنید.
3. **API ابری** را انتخاب کنید و آدرس سازگار با OpenAI که به `/v1` ختم می‌شود، کلید و نام دقیق مدل را وارد کنید.
4. ذخیره کنید و اتصال را آزمایش کنید.

کلید به‌صورت رمزنگاری‌شده ذخیره می‌شود و دوباره نمایش داده نخواهد شد. برای نگه‌داشتن کلید هنگام ویرایش سایر تنظیمات، فیلد کلید را خالی بگذارید. پیش از ارسال اطلاعات مشتری، شرایط ارائه خدمات در کشور خود و سیاست استفاده از داده‌های ارائه‌دهنده را بررسی کنید.

## ۶. هزینه و میزان استفاده

ارائه‌دهندگان براساس توکن هزینه می‌گیرند. هر صفحه متن تقریباً ۵۰۰ تا ۷۰۰ توکن است.

```
(توکن ورودی × قیمت ورودی + توکن خروجی × قیمت خروجی) ÷ ۱٬۰۰۰٬۰۰۰
```

| نمونه | تعداد توکن | هزینه با ورودی ۱ دلار و خروجی ۵ دلار به‌ازای هر میلیون |
|---|---|---|
| رکورد و تاریخچه | ۴۰۰۰ ورودی | ۰٫۰۰۴۰ دلار |
| خلاصه برگشتی | ۵۰۰ خروجی | ۰٫۰۰۲۵ دلار |
| یک درخواست | | حدود ۰٫۰۰۶۵ دلار |

| میزان استفاده تیم | درخواست ماهانه | هزینه ماهانه تخمینی |
|---|---|---|
| سبک: روزی ۱۰ درخواست کاری | حدود ۲۲۰ | حدود ۱٫۵۰ دلار |
| معمولی: روزی ۵۰ درخواست کاری | حدود ۱۱۰۰ | حدود ۷ دلار |
| سنگین: روزی ۲۰۰ درخواست کاری | حدود ۴۴۰۰ | حدود ۲۹ دلار |

این اعداد براساس قیمت نمونه بالا هستند. قیمت هر ارائه‌دهنده و مدل متفاوت است و تغییر می‌کند. خواندن یک پیشنهاد طولانی نیز توکن ورودی بیشتری از خلاصه‌سازی مصرف می‌کند. در این روش هزینه ثابت ماهانه وجود ندارد و بدون درخواست، هزینه صفر است.

### کنترل هزینه

- سقف روزانه شرکت و هر کاربر را تنظیم کنید.
- در حساب ارائه‌دهنده سقف هزینه قرار دهید.
- قابلیت‌های غیرضروری را خاموش کنید.
- اگر نتیجه مناسب است، برای خلاصه، پیش‌نویس و ترجمه از مدل کوچک‌تر استفاده کنید.

### مشاهده میزان مصرف

1. قیمت روز ارائه‌دهنده را در **هزینه ورودی / میلیون توکن** و **هزینه خروجی / میلیون توکن** وارد کنید.
2. بالای تنظیمات AI، **مصرف هوش مصنوعی** را انتخاب کنید.

این صفحه تعداد درخواست‌ها، درخواست‌های موفق، توکن ورودی و خروجی و هزینه تخمینی را به تفکیک روز و کاربر نشان می‌دهد. مبلغ صورتحساب ارائه‌دهنده، رقم نهایی و معتبر است.

## ۷. استفاده از قابلیت‌ها

### خلاصه‌سازی

یک مشتری، فرصت یا پروژه را باز و **✦ خلاصه‌سازی** را انتخاب کنید. پذیرش، متن را کپی می‌کند و رد کردن پنجره را می‌بندد. چیزی در رکورد ذخیره نمی‌شود.

### پیشنهاد گام بعدی

یک فرصت را باز و **✦ پیشنهاد گام بعدی** را انتخاب کنید. این قابلیت فقط برای فرصتی اجرا می‌شود که هفت روز فعالیت نداشته باشد.

### خواندن پیشنهاد تأمین‌کننده

1. استعلام را باز کنید و **✦ خواندن پیشنهاد تأمین‌کننده** را بزنید.
2. متن را جای‌گذاری کنید یا یک PDF متنی حداکثر ۱۰ مگابایتی انتخاب کنید.
3. تأمین‌کننده، مرجع، ارز، اقلام، قیمت‌ها، حمل و زمان تحویل را بررسی کنید.
4. تأمین‌کننده را انتخاب کنید و فقط پس از مقایسه با اصل پیشنهاد، **ذخیره** را بزنید.

PDF اسکن‌شده و تصویری متن قابل خواندن ندارد؛ متن آن را دستی جای‌گذاری کنید.

### پیش‌نویس پاسخ

در پنجره ایمیل یا پیامک، یک دستور کوتاه وارد کنید. پذیرش، پیش‌نویس قابل ویرایش را داخل متن پیام می‌گذارد و هیچ پیامی خودکار ارسال نمی‌شود.

### ترجمه

متن پیام یا یادداشت را وارد و ترجمه را انتخاب کنید. پذیرش، فیلد را با متن ترجمه‌شده جایگزین می‌کند.

## ۸. حریم خصوصی و محدودیت‌ها

- فقط رکورد باز، فیلدهای مجاز آن، حداکثر ۳۰ رویداد اخیر و متن واردشده برای همان درخواست ارسال می‌شود.
- رمزها، کلیدهای API، سایر رکوردها و اطلاعات کاربران دیگر هرگز ارسال نمی‌شوند.
- کاربر فقط روی رکوردهایی می‌تواند از AI استفاده کند که نقش او اجازه خواندنشان را دارد.
- اطلاعات مدل محلی روی رایانه Ollama می‌ماند؛ درخواست ابری به ارائه‌دهنده انتخابی می‌رود.
- برای هر درخواست، کاربر، قابلیت، رکورد، ارائه‌دهنده، مدل، تعداد توکن، مدت و نتیجه ثبت می‌شود؛ متن درخواست در لاگ ذخیره نمی‌شود.
- خروجی AI، به‌خصوص اعداد پیشنهاد تأمین‌کننده، ممکن است اشتباه باشد. پیش از ذخیره یا ارسال همیشه آن را بررسی کنید.

## ۹. رفع اشکال

ناموفق بودن درخواست AI هیچ بخش دیگری از CRM را متوقف نمی‌کند.

| پیام | علت | راه‌حل |
|---|---|---|
| AI is turned off | ارائه‌دهنده خاموش است | مدل محلی یا API ابری را انتخاب کنید |
| ai_not_configured | آدرس یا نام مدل خالی است | هر دو را پر و ذخیره کنید |
| AI connection failed | آدرس اشتباه است یا Ollama اجرا نیست | آدرس را بررسی و Ollama را اجرا کنید |
| AI provider HTTP 401 | کلید API نامعتبر است | کلید معتبر وارد و ذخیره کنید |
| AI provider HTTP 404 | مدل یا آدرس اشتباه است | هر دو را از مستندات ارائه‌دهنده کپی کنید |
| AI provider HTTP 429 | سقف نرخ یا هزینه ارائه‌دهنده پر شده | صبر کنید یا سقف را تغییر دهید |
| AI provider timed out | پاسخ بیشتر از مهلت طول کشیده است | مهلت را افزایش دهید یا مدل محلی کوچک‌تر انتخاب کنید |
| Your daily AI limit has been reached | سقف کاربر پر شده | سقف را افزایش دهید یا تا فردا صبر کنید |
| Company daily AI limit reached | سقف شرکت پر شده | سقف را افزایش دهید یا تا فردا صبر کنید |
| This AI feature is disabled | قابلیت خاموش است | آن را در تنظیمات AI فعال کنید |
| The AI result was not valid quotation JSON | مدل قالب درست برنگردانده است | دوباره امتحان کنید، مدل قوی‌تر به‌کار ببرید یا دستی وارد کنید |
| This deal has activity within the last 7 days | فرصت غیرفعال نیست | اقدامی لازم نیست |

اگر مدل محلی کند است یا فارسی ضعیفی دارد، اندازه بعدی مدل یا API ابری را امتحان کنید.

## ۱۰. چک‌لیست سریع

- [ ] روش اجرا مشخص شده است: خاموش، محلی یا ابری.
- [ ] محلی: Ollama نصب، مدل دانلود و مهلت حداقل ۱۲۰ ثانیه است.
- [ ] ابری: حساب، کلید، آدرس، مدل و سقف هزینه آماده است.
- [ ] آزمایش اتصال موفق است.
- [ ] سقف‌های روزانه تنظیم شده‌اند.
- [ ] قیمت توکن برای برآورد مصرف وارد شده است.
- [ ] اعضای تیم می‌دانند هر خروجی AI پیش‌نویس و نیازمند بررسی است.
